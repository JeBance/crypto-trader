# 📱 Termux Trading Bot

Автоматизированная система для трейдинга криптовалютными активами, работающая непосредственно на Android-смартфоне через эмулятор терминала **Termux**.

## 🚀 Возможности

-   **Поддержка бирж:** Интеграция с популярными CEX (Binance, Bybit, OKX) через API.
-   **Стратегии:** Встроенные индикаторы (RSI, MACD, Moving Averages) для принятия решений.
-   **Уведомления:** Отправка сигналов и отчетов о сделках в Telegram.
-   **Легковесность:** Минимальное потребление ресурсов смартфона.
-   **Безопасность:** Локальное хранение ключей, поддержка `.env`.

## 📋 Требования

-   Устройство на базе **Android**.
-   Установленное приложение **Termux** (рекомендуется версия с F-Droid).
-   Аккаунт на криптобирже с включенным **API**.
-   Аккаунт в **Telegram** (для бота-уведомлений).

## ⚙️ Установка

1.  Обновите пакеты и установите зависимости в Termux:
    ```bash
    pkg update && pkg upgrade
    pkg install python git
    ```

2.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/JeBance/crypto-trader.git
    cd crypto-trader
    ```

3.  Установите библиотеки Python:
    ```bash
    pip install -r requirements.txt
    ```

4.  Настройте конфигурацию:
    ```bash
    cp .env.example .env
    # Отредактируйте .env, вставив свои API ключи и токены
    ```

## ▶️ Запуск

```bash
python main.py
```
